git merge temp // temp라는 브랜치를 merge함

git branch -d "브랜치 명" <- 브랜치를 삭제

git restore --staged <file name> <- stage에 올라간 파일 내려두기

git remove - v // 현재 연결되어 있는 리포지토리의 주소를 확인 가능 .

5. 파일(소스코드) 수정 (지금 미션은 day2 수정)

7. pull request <- 상대가 바꾼 것에 대한 코멘트 남길 수 있음. //이건 add 하면 pull request 버튼이 생김

10. 원본 리포지토리(원격에 있는) 다시 클론 해서 사용.
